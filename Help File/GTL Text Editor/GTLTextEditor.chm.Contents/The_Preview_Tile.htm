The Preview Tile Area

 

LOCATION:

The lower center of GTL Text Editor (Default: Hidden)

PURPOSE:

Allows individual editing of the full, half, and small sized tiles.

USE:

  1. Add text to the half size tile images
  2. Change the color of the small tile
  3. To display the Preview Tile Area, de-select the "Automatically create tile from Working Tile" option in the Tile Menu .
