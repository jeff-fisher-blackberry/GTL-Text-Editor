Deleting Tiles

Tiles may be deleted from the GTL File Viewing Area in one of two ways:

Option 1:

    1. Select a tile/tiles in the GTL File Preview Area.  The selected tile/tiles will now be highlighted in BLUE
    2. Right click on the tile/tiles and select the "Delete tile" option.

Option 2:

    1. Select a tile/tiles in the GTL File Preview Area.  The selected tile/tiles will now be highlighted in BLUE
    2. Click on the delete tile button on the tool bar.
