Quick Start

 

  1. Open a saved GTL file.  The tile(s) will be displayed on the right-hand side in the GTL File Viewing Area .  The first tile image is displayed in the Working Tile Area and automatically set as the Base Tile .
  2. Add and position text using the text window and select the "Place" Button.
  3. Use the Scrollbars to position/rotate the text on the working tile.
  4. Continue to enter text, press "Place", and position the text.
  5. When the tile is complete press the "Create Tile" button to add the new tile to the GTL File Viewing Area.
  6. Save\Save As... the GTL File when you are done.
  7. Use Cyberboard Designer to import the saved file into the a Tile Image Group.
