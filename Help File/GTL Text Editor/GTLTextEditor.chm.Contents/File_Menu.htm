File Menu

 

Open

  • Open GTL files

Save

  • Save the current GTL file

Save As...

  • Save the current GTL file with a different name

Confirm when replacing file (Default: Selected)

  • When selected, requires confirmation of file replacement

Text Position Data

    • Save - Save the text position data for the nine position buttons.
    • Load - Retrieve any saved text position data and display it in the nine position buttons.
    • Clear -Removes all the text position data and reset the text entry box to Arial, 8 point.

Create bitmaps from GTL file

  • Saves each full size tile image as an individual bitmap file.  Each file is saved as <FILENAME>1.bmp, <FILENAME>2.bmp, <FILENAME>3.bmp, etc...

       See Creating Bitmap files from a GTL File

Exit

  • Exit GTL Text Editor
