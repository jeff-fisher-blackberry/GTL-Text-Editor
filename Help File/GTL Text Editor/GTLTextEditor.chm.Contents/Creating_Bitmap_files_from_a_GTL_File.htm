Creating Bitmap files from a GTL File

  1. Open the GTL file which contains the tiles you would like converted to bitmaps
  2. From the File menu select "Create bitmaps from GTL file"
  3. Choose a "standard" name for the bitmap files.
  4. The bitmaps will be created using the "standard" name followed by the digit count of the file.

(ex..  "Standard" name = Tile: Tile1.bmp, Tile2.bmp, Tile3.bmp...)
