Working with GTL files in Cyberboard Designer

Saving Tile Library Files for use in GTL Text Editor

1. Select the tile(s) to be used in GTL Text Editor.

 

2. From the Project menu select "Save Tile Library File..." and save the selected tiles.

Loading Tile Library Files from GTL Text Editor.

1. Select the TILE IMAGE GROUP the GTL File will be loaded into.

2. From the Project menu select "Load Tile Library File..." and load the selected tiles.

3. The completed tiles will be loaded into the selected TILE IMAGE GROUP.
