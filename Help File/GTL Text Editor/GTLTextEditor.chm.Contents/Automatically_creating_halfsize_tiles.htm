Using GTL Text Editor Automation Features

The automation features of GTL Text Editor are controlled using the Tile Menu.

 

Using "Automatically Paste Base Tile When Tile Is Created"

Purpose: Designate a "Base" tile which is copied to the Working Tile Area as the default tile image when tiles are created.  This prevents you from having to select a tile image every time you create new tiles.

 

Use: See Setting the Base Tile

Using "Automatically Create Tile From Working Tile"

Purpose: Decrease the number of button pushes required to create tiles.  All tiles created are done so using only the Working Tile image.

 

Limitations: The half size tile image and small tile color CANNOT be edited with this option selected.  You must de-select this option to add text to the half size tile image or change the color of the small tile.

 

Use: Select this option from the Tile Menu.

 

Using "Automatically Create Halfsize Tile"

Purpose: Create half size tile image using the full size tile image.

 

Limitations: Text may be illegible on half size tiles.

 

Use: Select this option from the Tile Menu.

 

Using "Create Tile Using Position Data"

Purpose: Aid in the rapid creation of tiles where only one or a few text items change.

 

Use:

    1. Select the "Base" image and designate it as the Base Tile.
    2. Place all required text on the tile and "Store" each in the Text Position Data Buttons.
    3. Select the "Create tile using position data" option in the Tile Menu.
    4. Make the text changes in the Text Position Data Area and press the "Create Tile" button to rapidly create individual tiles.
