The Base Tile

 

LOCATION:

The Black Highlighted tile located within the GTL File Viewing Area .

PURPOSE:

Allow a specific tile image to be pasted to the Working Tile Area after a tile has been created. 

  • "Automatically paste base tile when tile is created" option MUST be selected in the Tile Menu
  • Aids in multiple tile creation.

USE:

  1. Select a tile in the GTL File Preview Area.  The selected tile will now be highlighted in BLUE. 
  2. Right click on the tile and select the "Set as Base tile" option.
  3. The selected tile will become highlighted in BLACK signifying it is now the Base Tile.
  4. After a new tile is created the Base Tile image will be copied to the Working Tile image.
